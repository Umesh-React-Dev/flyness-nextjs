# ✈️ Flyness Next.js

A modern, responsive flight booking web application inspired by the Flynas booking experience. This project is built using **Next.js**, **React**, **TypeScript**, and modern frontend best practices to deliver a fast, scalable, and user-friendly application.

> **Reference Website:** https://www.flynas.com/en/flights

---

## 🚀 Features

- 🔍 Flight search (One-way, Round-trip, Multi-city)
- 📅 Date selection
- 👥 Passenger & Cabin Class selection
- 🎟️ Promo Code support
- 📱 Fully Responsive Design
- ⚡ Server-Side Rendering (SSR)
- 🔄 Reusable Components
- 🌙 Clean and Modern UI
- 🔐 TypeScript Support
- 📦 Optimized Project Structure

## ⚙️ Getting Started

### Clone Repository

```bash
git clone https://github.com/Umesh-React-Dev/flyness-nextJs.git
```

### Install Dependencies

```bash
npm install
```

### Start Development Server

```bash
npm run dev
```

Open:

```
http://localhost:3000
```
